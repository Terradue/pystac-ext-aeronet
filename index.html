AERONET PySTAC extension¶

pystac-ext-aeronet reads and writes AERONET station metadata on pystac.Item objects. Import AeronetExtension from pystac.extensions.aeronet.

AERONET (AErosol RObotic NETwork) is an international network of ground-based aerosol observations. Its measurements support aerosol research and satellite retrieval validation.

The Terradue AERONET STAC extension describes stations through their site name, land use, and days of data availability. This package supplies Python accessors for those fields. It does not download observations or calculate availability counts.

python -m pip install pystac-ext-aeronet
